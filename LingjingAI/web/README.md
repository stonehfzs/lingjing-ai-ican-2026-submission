# 镜序前端

原生 HTML / CSS / JavaScript，无构建依赖。由项目的本地服务器把本目录作为静态资源目录提供，打开服务器首页即可。

## 文件

- `index.html`：剧本与镜头列表、画布、检查器、付费生成确认框。
- `style.css`：深色电影制作工作台，暖橙强调色；缩小窗口时收紧侧栏。
- `app.js`：画布交互、本地服务 API、项目与生成任务管理。

## 操作

1. 左侧切换至“剧本”，粘贴文本或导入 UTF-8 `.txt` / `.md`，保存项目。
2. 点击“复制给 Codex 的指令”，由 Codex 读取项目并编排分镜。前端只保存剧本原文，不把规则切句伪装为 AI 分镜。
3. 点击左侧镜头定位画布。拖动节点调整坐标；拖动空白处平移；滚轮缩放。“横向排版”按镜头列表順序重新排列，并重建顺序连线。
4. 在右侧编辑动作、景别、运镜、提示词、参考图片路径。静帧/视频切换会重新提供该类型的模型与默认参数。
5. “生成这一镜”先展示模型、实际提交参数、参考图数量和提示词。只有点击“确认并生成”才向服务器提交付费任务。
6. 可查看生成记录、手动查询已有任务；本地生成媒体直接在节点内显示，视频带播放控件。截取秒数只改变输出文件，模型仍按原始生成时长结算。
7. Ctrl+S / Command+S 保存；导出可保存全部分镜、坐标、连线、原文及模型设置的 JSON。

## 协作与边界

- 所有写请求携带 `X-Studio-Request: 1`，生成额外携带 `confirmed: true` 与 UUID `requestId`。
- 提交失败不会自动重复提交；相同参数在结果不明确时沿用相同请求 ID，由服务端幂等处理。
- 每 6 秒读取状态、项目和任务列表；隐藏标签页停止轮询。生成刷新操作只查询已有任务。
- 无未保存编辑时自动载入外部版本。存在未保存编辑时保留本地内容并提示外部更新；保存冲突的 HTTP 409 不会强制覆盖。
- 表单使用文本节点渲染输入。节点仅展示同源 HTTP(S) 媒体，避免导入文件注入脚本或外部媒体地址。
- API 契约以项目根目录文档为准；前端不直接访问登录状态、积分凭据或 MiniMax 内部网关。

验证：`node --check web/app.js`。
