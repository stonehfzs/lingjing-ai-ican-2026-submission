# 镜序 0.3 创作界面

`creator.js` / `creator.css` 提供项目库、剧本、分镜审阅与资源管理；`graph.js` / `graph.css` 提供真实工作流画布。`shots.html` 保留旧镜头编辑器。

- **项目**：打开项目库创建或切换独立工作区。所有项目请求固定携带当前 `X-Studio-Workspace`；媒体使用后端给出的工作区 URL。切换会清空上一个项目的节点、预演和资源缓存。
- **剧本**：阅读保留原文的段落，查看关联镜头，从段落新建镜头或关联到当前镜头。导入原文不会伪称自动完成分镜。
- **分镜**：按场次浏览真实素材及画面参考。点击镜头进入专注审阅：只显示画面、正文、对白、实际音轨与审阅意见，支持上一镜/下一镜。正式生成结果和参考图分别标识。
- **资源**：导入、拖入、试听与分类查找图片、声音、视频或文字。图片显示真实文件，音频仅使用后端提供的真实波形数据；没有波形时提供原始音频播放器。可将资源放到画布，或关联当前镜头。
- **节点**：拖动端口建立真实依赖；点击节点弹出设置卡片，不常驻占据画面。图片、音频、视频和文字分别使用对应端口。
- **引用**：连入资源后，可在提示词使用 `@{assetId}` 或资源名称按钮。绑定记录分别指定模型参考、音色身份、后期混音和文字上下文；断开连接后，不会保留该连接产生的有效模型绑定。未解析的残留引用由预演明确报错。
- **声音**：使用实际镜头的声音计划与绑定。未分类的音频在关联时选择用途；音色身份不能当作实际台词表演，环境声与音乐默认留作后期。
- **执行**：依赖检查与预演不提交生成。正式提交先预演，然后在确认窗核对镜头、模型、数量、实际图片/音频引用、生成时长和裁切起点。用户最后确认才发送稳定 requestId；响应不确定时不会自动重发。

工作流保存使用 revision 并发保护；镜头编辑通过 PATCH shot 使用 project revision，并由服务端同步图。冲突保留草稿，不覆盖远程更新。

界面使用本机 Noto Sans SC / Segoe UI Variable / Microsoft YaHei UI；剧本正文使用 Noto Serif SC。无需联网下载字体。

声音资源页支持创建角色声音：填写名称、描述与试听文本（最多500字），核对后才提交。设计结果为voice_identity候选，先试听再选用。审阅中的逐句生成仅使用已绑定vendorVoiceId与实时目录中本机适配器支持的Speech 2.8模型；实际台词和模型需要单独核对，声音设计试听不会代替正式对白。
