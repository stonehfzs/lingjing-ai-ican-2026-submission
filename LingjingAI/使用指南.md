# 灵镜AI 0.12 使用指南

双击桌面 **灵镜AI** 即可打开独立桌面软件。启动时自动检查并拉起本机服务；顶部项目按钮用于新建、切换工作区。原《苍头》资料不被改写，新剧本使用独立工作区。

## 先完成一条短片

1. **剧本 → 分镜**：建立项目，导入真实剧本；让 Codex 通读并整理角色、场景、镜头、对白和连续性。分镜卡可专注审阅，修改依据仍关联原文。
2. **资料库 → 节点**：导入照片、参考录音、视频，按人物分组；点“放到节点画布”，从素材节点端口连到生成节点。在提示词中用 `@` 选择实际连接的素材。参考身份、首帧、对白表演是不同用途。
3. **生成 / 声音**：选择模型、镜头与参数，检查实际输入。Design 云端任务会消耗账号积分；本机声音、字幕和剪辑不扣 MiniMax 积分。任务失败不会悄悄切到收费模型。
4. **任务 → 送到剪辑素材箱**：先审听/审看结果，再把候选送入剪辑。也可在剪辑顶部点“项目素材”“个人资料库”，或“＋导入”本地文件。
5. **剪辑 → 导出成片**：素材从左侧拖到下方时间线；调整画面、声音和字幕，导出后直接预览，成片回到本项目资源库。桌面版可“打开文件位置”。

## 可视剪辑

现在使用多轨编辑器：左侧素材箱、中间画面预览、右侧属性、下方时间线。面板分界线可拖动；“重置布局”恢复默认。上方可选横屏、竖屏、方形及帧率。时间显示为 **时:分:秒:帧**，最后一项不是百分之一秒。

| 操作 | 使用方式 |
|---|---|
| 添加与移动 | 拖素材到 V 视频轨或 A 音频轨；双击素材也会放到播放头。拖片段本体移动，边缘手柄裁切。 |
| 分割 | 选中片段，定位红色播放头，点“分割”或按 `Ctrl+K` / `S` / `Ctrl+B`。 |
| 复制、粘贴、剪切 | 选中时间线片段，`Ctrl+C` / `Ctrl+V` / `Ctrl+X`。粘贴到当前播放头；关联音画一起复制。 |
| 撤销、重做 | 时间线工具栏，或 `Ctrl+Z` / `Ctrl+Shift+Z`。输入框里的快捷键处理文字。 |
| 音画分离 | 选视频，点“音画分离”；原声成为独立音频片段，可单独移动/删除。若本来无声，会提示。分离不等于去背景音乐。 |
| 删除与补空隙 | `Delete` 删除选中片段；“定位间隙”“删除间隙”处理空档。吸附可开关。 |
| 预览 | 空格播放/暂停；`J/K/L` 后退/暂停/前进；拖动播放头。预览按当前轨道开关与音量混合。 |
| 画面与音量 | 选中片段后在右侧改缩放、位置、裁切、速度、音量、声像；可用关键帧、转场和调整层。 |
| 保存 | 自动保存，或 `Ctrl+S`。每个项目剪辑有自己的版本；冲突时保留本地草稿，设置里可“导出草稿”。不要用另一窗口强行覆盖。 |

**流畅预览**：选择视频素材后点“流畅预览”，生成本机720p代理；未选素材时处理素材箱中的视频。代理只用于预览，导出使用原素材。首次生成需要时间与磁盘空间。已测8秒多切点样片，桌面预览按时长正常播放，视频解码丢帧为0；复杂4K、多层特效仍受电脑性能影响。

**自动字幕**：先将对白或带声音的视频放上时间线 → 点“自动字幕” → 选中文/自动识别、顶部/中间/底部 → 识别 → 核对识别稿 → 应用。默认替换旧自动字幕，保留手工标题。字幕作为 V3 文字片段出现；选中后可直接在预览中拖位置、在右侧改字与样式，也能裁切时间。识别结果需要人工校对。

**导出**：点“导出成片”，选整个时间线或入出点范围，优先用“高质量导出”。字幕、文字与视觉效果会合成进新MP4，声音混合到AAC轨；完成后弹出成片预览并登记到资源库。导出期间保持窗口打开，不能切换项目；可以取消。旧版 `/api/timeline` 的 MP4+SRT 导出仍保留给历史项目，和新剪辑器是两份独立时间线，不能混写。

旧时间线第一次打开新剪辑器时复制迁入；旧文件保留。剪辑内核基于 MIT 授权的 FableCut，详见 THIRD_PARTY_NOTICES.md。已具备常用剪辑操作，但尚未等同 Premiere/剪映全部能力：没有剪映模板/素材商店、AE插件、复杂多机位剪辑和一键全片智能成片。上游的一些高级属性仍显示英文。

## 个人资料库

顶部“资料库”跨项目共用，数据只存本机 `personal-library` 文件夹。新建人物/分组，导入形象照、录音、视频。桌面版可多选文件；浏览器也支持上传，小于64MB用上传，较大文件用绝对路径。

“资料”可修改名称、分组、用途、录音原话和备注；“归档”收起不用的版本，“查看归档资料”可恢复。加入项目时复制固定版本，之后修改资料库不会悄悄替换已在制作的镜头。删除外部原文件不影响已导入副本。资料库目前没有自动收集你的照片和声音，需由你选择首次导入内容。

- 形象照：用途选“形象照片”，连接到需要身份参考的节点。
- 声音样本：用途选“声音参考”，填写准确录音原话。进入项目后可用于本机TTS或换声。
- 本镜对白：用途选“台词表演”，只绑定对应角色和准确台词，不把试听当正式对白。
- 剪辑中点“个人资料库”可选择素材进入素材箱，随后拖到时间线。

## 声音制作与本机模型

| 工具 | 输入与用途 |
|---|---|
| Qwen3-TTS | 干净单人参考录音＋原话＋新台词，生成参考声线的新对白；逐句试演、调整停顿后再选用。 |
| Seed-VC | 源表演录音＋目标声线录音，保留源台词与表演做换声。 |
| dots.tts.edit | 校对后的原台词＋局部改词/表演指令，生成精修候选；时长与发音仍需复查。 |
| MuseTalk 1.5 | 15秒以内单人正面视频＋不长于视频的对白，生成口型候选。检查嘴部、牙齿与脸部融合。 |
| faster-whisper | 识别声音得到带时间点文本与SRT；剪辑内“自动字幕”还会生成可视文字轨。 |
| FFmpeg | 提取完整音轨、裁切、预览代理、混音和成片导出。 |
| Demucs | 人声/其余声音分离；不能按演员拆分每个人，也不能保证无残留。 |

这些工具已有本机实测记录，模型状态以“本机模型”面板为准。RTX4060 8GB上的AI声音任务串行执行；缺模型或失败会说明原因。基础声线、逐句情绪和口型要分别审阅，能运行不代表配音演得好。

画内对白先用视频模型生成，再用换声保留表演，是可选方法。直接用不同节奏的TTS覆盖，往往需要再次对口型。旁白、画外声、环境音、音乐可以直接分轨后期添加。Design的声线设计、Speech、Seed Audio及云端克隆仍可能收费，与本机模型分开。

## 启动、服务与资料位置

桌面程序：`desktop/dist/JingxuStudio-win32-x64/JingxuStudio.exe`。保留整个软件目录，不能只移动单个exe；当前安装引用本机Python、Node及模型环境。不是联网下载器，每次打开不会重新下载模型。

关闭桌面窗口后，后台生成任务可继续；再次启动复用同一服务。剪辑导出依赖窗口，必须完成或取消后再关闭。需要彻底停止时先保存并退出桌面，再运行根目录 `Stop Studio.cmd`。

项目数据在各 workspace；新剪辑在 `<workspace>/data/editor-v7`，成片在其 `exports`，回收副本在该 workspace 的 `media/assets`。个人库在软件根目录 `personal-library`。备份应包含软件的 workspace 注册表、各项目数据及媒体、个人资料库；模型可重新下载，项目数据不能用空模板重建。

后台日志：`data/desktop-server.log`、`data/desktop-server-error.log`；剪辑服务日志在项目的 `data/editor-v7`。如果提示端口被其他程序占用，启动器会停止并报告，不结束其他服务。API及Codex自动化用法见 API.md；流程技能为 minimax-storyboard-studio。


## 0.8：右键剪辑、片段效果与模型工具

原“镜序 Studio”现在显示为“灵镜AI”，项目目录与保存数据沿用原位置。新快捷方式使用丁真头顶橙色像素螃蟹的Q版图标；完整Logo和无字图标在web/branding，原图为透明PNG。

右键时间线片段可剪切、复制、粘贴、在播放头或鼠标位置分割、删除、音画分离、打开效果或模型处理。右键空白位置可粘贴到该时间。Ctrl+X/C/V剪切复制粘贴；Ctrl+K分割所选片段；Ctrl+Shift+K分割全部轨道；C切换剃刀，点击片段切开；V返回选择；Ctrl+Shift+L音画分离。Ctrl+D现在是默认淡入淡出，重复片段改为Ctrl+Alt+D。快捷键在文字输入框中仍用于文字编辑。

“片段效果”集中提供电影、青橙、黑白、暖阳、冷夜、复古和柔光调色；淡入淡出、滑入、缩放与擦除；缓慢推拉、轻微手持与胶片颗粒；声音淡入淡出、打字和逐词字幕。应用后立即预览，右侧属性可细调；可撤销。推拉或声音淡入淡出会设置对应缩放/音量关键帧，使用前留意已有动画。

“本机模型”处理当前选中片段的真实入点/时长：FFmpeg提轨、Demucs人声分离、Whisper字幕、Qwen参考声线配音、Seed-VC换声、dots局部配音精修、MuseTalk口型。部分操作需要选择项目中的参考/驱动录音。素材中的原声作为输入，不烘焙时间线的调色、音量或其他效果；变速片段先导出再处理，避免误用整条源文件或错时长。

任务完成后在卡片中试听/试看，选择“加入素材箱”或“放入新轨道”。放入新轨道保留原素材，默认勾选静音原片段及关联原声，避免叠加双重对白；可取消勾选。原片段若已移动或裁切，软件拒绝自动放回，改从素材箱手动安排。关闭工具卡不会取消已提交任务，可在顶部“任务”查看。片段字幕回填会替换该范围重叠的自动字幕，保留手工标题及其他范围字幕。

导出支持自定义文件名、整个时间线/入出点/所选范围、跟随画布或长边1280/1920/3840。所选范围包含该时段其他启用轨道。输出尺寸只改变交付文件，不修改原时间线画幅和坐标；保持比例，放大不会增加真实细节。改变尺寸会使用本机逐帧合成导出。常规交付选择MP4 H.264；ProRes MOV用于后续Pr剪辑，内置预览可能不支持。界面显示实际尺寸、帧率、秒数和帧数。


## 配音调试台（0.10）

顶部点 **配音调试**，或在“声音”页面打开调试台。调试台按当前项目显示角色、试听历史和可用本机模型；每个workspace的草稿与试听相互隔离。

编辑区用“声线”描述音色，用“表演”说明本句的对象、目的和转折，“台词”只填写实际说出的文字（最多200字）。模式选“设计声线 · 1.7B”创建候选音色，或选“固定声线 · 0.6B”用已选试听/声音参考读新台词。固定声线模式需要准确填写参考原话，不接受自由表演指令。名称、种子、变化和设备收在“参数”折叠区；`Ctrl+Enter`可生成试听。

生成按钮和试听卡显示排队、加载模型、合成、保存音频等真实阶段。处理中阶段没有可靠百分比时显示不定进度；成功后只有音频验证可试听才显示完成。每条进行中的试听可取消。短暂断连会自动重试，重新打开同一项目也可继续查看后台记录。

试听列表支持搜索和筛选。使用A/B把版本加入对比；播放一条会暂停另一条，共同音量只影响播放器。点击“固定声线”可将该试听作为后续参考；点击“入库”后选择保存用途与项目资源库或个人资料库，确认后才写入。试听与参数继续保留，入库不会自动替换全片对白。版本的“参数”菜单中可“套用参数”回到编辑区。

工具栏“恢复”可载入已保存配置；“保存”保存当前配置，编辑内容也会自动保存并保留本机草稿。版本冲突时先恢复或重新载入已保存配置，再继续编辑。

**本机模型实测**：Qwen3-TTS-12Hz-1.7B-VoiceDesign已从官方HF固定版本下载并校验，模型文件合计约4.52GB，共用Tokenizer复用已有文件。RTX4060 8GB使用BF16/SDPA离线生成5.36秒样本，约27.9秒，峰值分配显存约4.01GiB、峰值预留约4.11GiB。固定样本读新台词的0.6B Base样例为3.12秒音频、约24.2秒处理。它们是短样本实测，不保证所有台词同速。

本地生成不消耗MiniMax积分。VoiceDesign当前验证NVIDIA GPU；Base已验证CPU/GPU。模型运行成功不代表台词、自然度、人物贴合度已通过。建议逐句试听，不一口气生成全片。自动ASR只辅助校字；样本识别存在“那天/那一天”等差异时，需人工听清后确定参考原话。

位置：模型在`.runtime/speech-models/voice-design`；各项目的`data/voice-lab.json`保存配置和试听历史，音频在`media/voice-lab`；手动入库后复制到项目`media/assets`或全局`personal-library`。技术验收样本在独立“本机工具验收 v0.6”项目，《苍头》的角色与正式资源未被测试音频替换。
