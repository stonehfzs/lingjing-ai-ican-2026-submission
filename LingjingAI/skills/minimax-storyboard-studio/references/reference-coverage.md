# 先列画面需求，再查引用

| 可见需求 | 所需依据 | 常见遗漏 |
|---|---|---|
| 清晰脸 | 同人身份与合适角度 | 双人镜只接一人、年龄错 |
| 半身/全身/背影 | 本阶段体型与服装 | 只有脸；背影强加正脸 |
| 伤势/摘帽/湿衣 | 明确入镜与出镜状态 | 起始图已受伤却要求镜内才受伤 |
| 正反打/日夜 | 同空间几何、光位、轴线 | 镜像翻转伤势和持物 |
| 叙事道具 | 同实例图片与规范 | 杯/刀形状跳变，持物复制 |
| 手部/局部 | 道具、材质、袖口、人物归属 | 全部人脸入画，关键器物无依据 |
| 群体/路程 | 分布、方向、时令、服装约定 | 复制主角脸，雨营地代替行军路 |
| 复用/后期 | 来源镜头与帧段 | 生成近似版伪装复用 |

普通背景物可用文字规范；反复近拍、承载变化的物件优先锁图。身份/环境资产不是首帧，参考板不能冒充已审构图。关键双人尺度、交互与反打先做场面试验，再扩同场。模型容纳不了引用时先合成忠实首帧/拆镜，不能静默丢输入。

requirements 字段：id、label、category、mediaType、usage、assetIds（替代项）、assetHashes（版本）、reason、gapKey（跨镜缺口）。必须真实存在、正确用途、已启用；文件存在不证明语义合适。自动报告检查声明需求的结构覆盖；Codex 仍须看图并检查需求漏项。

绑定后用 @{assetId} 或唯一 alias。编译后核对 referenceBindings 和 image/audio/videoPaths；context/voice_identity/post_mix 不得偷偷成为模型媒体。切换模型重新检查合同。

continuityIn/Out 明确前后状态；continuityLinks 指向因果来源及须相等的 keys。人物自身左右、伤口、持物、布/杯实例、雨势用明确值，不能只写“按前镜”。画外状态留在场记，仅在可见时写入画面指令。

报告分开参考可用、接口可编译、正式声音可用、成片已审。首帧批准不批准未来动作，声线批准不批准全部台词；原文/动作变更后分析过期，重新分析再更新哈希。
